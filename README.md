# UAVoiceTTS — українська озвучка квестів для WoW Forever

Безкоштовний аддон для **World of Warcraft Forever**, який озвучує тексти квестів українською — голосами NPC, що відповідають расі та статі квестодавця. Новини, релізи та скарги на озвучку — у нашому [Discord](https://discord.gg/AgGnWCG38S).

Ми озвучуємо український переклад квестів від [ClassicUA](https://www.curseforge.com/wow/addons/classicua). Аддон самостійний: субтитри вже всередині, встановлювати ClassicUA не обов'язково (але з ним і тексти у вікнах квестів будуть українською).

> ⚠️ Неофіційний фанатський проєкт. Не пов'язаний з Blizzard Entertainment. Аддон перевірено лише на WoW Forever; на інших клієнтах Classic не тестувався.

## Встановлення

1. Розпакуйте `UAVoiceTTS.zip` у `World of Warcraft/<папка вашої версії>/Interface/AddOns/` (наприклад, `_classic_beta_` для бети WoW Forever). Має вийти папка `AddOns/UAVoiceTTS`.
2. **Повністю перезапустіть гру** — нові звукові файли не підхоплюються через `/reload`.
3. Увімкніть аддон у списку аддонів на екрані вибору персонажа.

## Можливості

- Опис квесту звучить після того, як ви його **взяли**, текст завершення — під час **здачі**.
- **Черга**: репліки не перебивають одна одну, а грають по черзі; панель з кнопками «Наступний», «Повторити», «Зупинити й очистити чергу», «Поскаржитися».
- Субтитри на панелі.
- Кнопка **«Прослухати»** у вікні квесту NPC та в журналі квестів (карта).
- Окремі версії для героя й героїні, коли текст звертається до гравця.
- **Історія** прослуханого: Налаштування → AddOns → UAVoiceTTS (кнопки «Слухати» і «Скарга»).

## Команди

| Команда | Дія |
|---|---|
| `/uavoice` | меню з налаштуваннями та історією |
| `/uavoice on` / `off` | увімкнути / вимкнути озвучку |
| `/uavoice skip` | наступна репліка в черзі |
| `/uavoice stop` | зупинити й очистити чергу |
| `/uavoice sub` | субтитри |
| `/uavoice accept` / `complete` | читати опис при взятті / текст при здачі |
| `/uavoice panel` / `reset` | показати панель / повернути її на місце |
| `/uavoice report` | скарга на останню репліку (`report N` — на N-ту з історії) |
| `/uavoice list` | 10 останніх реплік |
| `/uavoice discord` | усі ваші скарги одним текстом для Discord |
| `/uavoice test` | перевірка звуку |

## Скарги на озвучку

Неправильний наголос, обірвана фраза, дивні звуки? Натисніть **«Поскаржитися»** (на панелі або в історії), оберіть причину, для наголосу впишіть слово з **великою наголошеною літерою** (`впОрався`). Аддон дасть рядок виду

```
UAV#1;364;a;m;364_accept.ogg;наголос;тварЮками;
```

Скопіюйте його (Ctrl+C) і надішліть у канал [**#скарги**](https://discord.gg/mddCxzAkjB) нашого Discord. Слова з наголосом потрапляють у словник, і всі репліки з ними переозвучуються.

## Як це зроблено

Озвучка генерується локально (без платних сервісів) на Mac з Apple Silicon:

- **Модель**: Higgs Audio v3 (4B) через MLX / `mlx-audio` з власним LoRA-адаптером для природної української інтонації.
- **Голоси**: для кожного NPC обирається голос за расою і статтю, відміну нежиті дає ефект «склеп» (реверберація).
- **Тексти**: ClassicUA; ім'я, клас і раса гравця замінюються на «герой/героїня», «мандрівник/мандрівниця» у правильному відмінку.
- **Контроль якості**: кожну репліку розпізнає Whisper; при розбіжностях, довгих паузах чи неприродному темпі — перегенерація.
- **Наголоси**: ручний словник (`code/prod/stress_dict.txt`), що поповнюється зі скарг гравців.
- Вихід: OGG Vorbis, моно 24 кГц, з вирівнюванням гучності.
